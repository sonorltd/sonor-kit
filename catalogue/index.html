Sonor Kit

The shared components every Sonor app uses — served, not copied. One line loads the whole kit; the same element works in a vanilla page and in React 19.
<script type="module" src="https://sonorltd.github.io/sonor-kit/v1/kit.js"></script> <!-- local dev: ?kit=local on the page URL, or data-kit-base="../sonor-kit/v1/" -->
